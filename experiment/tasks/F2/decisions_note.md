# Extra requirement: decision log
While working, keep `DECISIONS.md` at the repo root. For every notable design or implementation decision (layout,
component structure, state handling, error/empty states, accessibility, responsiveness, anything you were unsure about)
add 1–3 lines: **Decision** — alternatives you considered — **why** you chose it. Also list things you deliberately
did NOT do and why. Be honest; this log is used to improve future instructions, not to grade you.
